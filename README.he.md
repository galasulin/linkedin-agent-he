## מה זה

אני מנהל IT. יש לי דברים אמיתיים להגיד על שרתים, גיבויים, רשתות וסייבר, ואין לי זמן להילחם בעורך ריק. כלי כתיבה כלליים מוציאים עברית מתורגמת ומלוטשת מדי, שמזהים אותה מהשורה הראשונה.

אז בניתי סקיל ל-Claude שכותב **בעברית ישראלית טבעית, בקול שלי**, על **שרתים, IT וסייבר**, ו**לא מפרסם שום דבר שלא אישרתי מילה במילה**. כל טיוטה עוברת בודק עברי מקומי שמתקן טיפוגרפיה, מסמן סימני AI ומדרג את הטקסט לפני שאני רואה אותו.

### הכללים שלא נשברים

1. **טיוטה ← אישור ← פרסום.** שום דבר לא עולה בלי "כן / תפרסם / מאשר" מפורש לאותו טקסט בדיוק. כל שינוי אחרי אישור = שואלים שוב. אישור לפוסט אחד הוא אף פעם לא אישור לפוסט הבא.
2. **בלי להמציא.** מספר חסר הופך ל-`{{המספר שלך}}`, ואין פרסום כל עוד נשאר `{{` בטקסט.
3. **פרסום דרך הדפדפן שלי.** הפוסט המאושר מוקלד ללינקדאין דרך Playwright במחשב שלי, שבו אני מתחבר בעצמי. לחיצה אחת על "פוסט", ואז בדיקה בפיד הפעילות שהפוסט מופיע פעם אחת בדיוק. בלי גרידה, בלי לייקים אוטומטיים, בלי תגובות אוטומטיות, בלי הודעות בשמי. תגובות, מענים והודעות מגיעים מוכנים להעתקה, ואני מדביק אותם.
4. **כל טיוטה עוברת humanizer וציון** לפני שאני רואה אותה. מוצג הטקסט הנקי יחד עם הציון, אף פעם לא הציון לבד.
5. **סודיות.** בלי שמות לקוחות או מטופלים, שמות שרתים, כתובות IP או פרטי אבטחה של ספקים, אלא אם כתבתי אותם בעצמי.

### ה-humanizer העברי (`scripts/he_check.py`)

קובץ אחד בלי תלויות, שבנוי למורפולוגיה של עברית (אותיות השימוש ו/ה/ב/כ/ל/ש/מ):

- **מתקן אוטומטית** תווים בלתי נראים, קווים מפרידים ארוכים, מירכאות מסולסלות, שלוש-נקודות ותבליטים;
- **מסמן** 61 ביטויי AI שחוקים בעברית ("בעולם של היום", "חשוב לציין", "לסיכום", "למנף"…), כל אחד עם סיבה והצעת תיקון, ו-9 סימני מבנה ("לא רק… אלא", "זה לא X, זה Y", שורת חשיפה מבוימת, שלישיות, אימוג'י של AI, קיר האשטגים, פיתיון מעורבות, ניקוד);
- **מדרג** חמש בדיקות (קצב, קונקרטיות, ביטויים שחוקים, טביעת אצבע, קול) לציון אנושי 0-100: ‏`PASS` מ-70 ומעלה, בלי בדיקה מתחת ל-55.

<div dir="ltr">

```text
python scripts/he_check.py examples/sample-draft.txt --fix   # 18.0  FLAGGED
python scripts/he_check.py examples/sample-final.txt         # 86.1  PASS
python tests/test_he_check.py                                # 3 smoke tests
```

</div>

זו היוריסטיקה מקומית ולא גלאי AI מסחרי, והסקיל אף פעם לא טוען שטקסט "בלתי ניתן לזיהוי". שתי הדוגמאות בדיוניות, לא פוסטים אמיתיים.

## ארכיטקטורה

![Architecture](docs/showcase/architecture.png)

הסקיל הוא קובץ `SKILL.md` אחד ש-Claude טוען כשאני מבקש עבודה על לינקדאין. הוא קורא שני קבצים פרטיים מה-Google Drive שלי (`voice-he.md`, פרופיל הסגנון, ו-`log-he.md`, שורה לכל פוסט שפורסם), בוחר מצב וכותב טיוטה. שלב ה-humanizer כותב את `he_check.py` (מוטמע מילה במילה ב-`SKILL.md`, זהה ל-`scripts/he_check.py`) לתיקיית העבודה של השיחה, מריץ אותו עם `--fix`, משכתב כל שורה מסומנת ומריץ שוב עד שהטקסט עובר. כרטיס האישור הוא השער היחיד לשכבת הפרסום: ‏Playwright MCP מפעיל את הדפדפן במחשב שלי, מקליד את הטקסט המאושר בדיוק, לוחץ "פוסט" פעם אחת, מאמת בפיד ומוסיף שורה ליומן.

## התקנה

מעתיקים את `SKILL.md` לתיקיית הסקילים של Claude בשם `linkedin-agent-he`, מחליפים את `{{PROFILE_HANDLE}}` בכינוי שלכם בלינקדאין, ומחברים דפדפן Playwright MCP שאתם מתחברים אליו בעצמכם.
